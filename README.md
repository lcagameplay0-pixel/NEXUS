# NEXUS

NEXUS é um centro de controle modular para Windows.

## Versão
1.0.0

## Tecnologias
- Python
- PyWebView
- HTML
- CSS
- JavaScript

## Executar

    .\.venv\Scripts\python.exe app.py

## Estrutura
- core: lógica principal
- modules: módulos independentes
- ui: interface
- tests: testes automatizados

## Idioma
Português do Brasil
